# Changelog

## 0.2

- Allow one–four lines in each existing message while preserving its code 101 header, settings, escape codes, and surrounding commands.
- Add native MV face-sheet portrait previews, with notices for unavailable assets.
- Add compact page overview, click-to-jump, Previous/Next shortcuts, and Find Next.
- Check destination free space before making a full working copy.
- Expand safety tests and exercise the real Tk GUI under a virtual display.

v0.2 is separate from `main`; v0.1 remains available unchanged at tag `v0.1` (commit `33e4a9874db545874fbf4586f2b40849ac9925d0`).
